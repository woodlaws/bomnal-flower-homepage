# 봄날플라워

동네 꽃집을 주제로 만든 한국어 한 페이지 홈페이지입니다. 강의용 가상 가게이며 실제 주문이나 상담은 제공하지 않습니다.

## 파일 구성

- `index.html`: 상단 메뉴, 메인 배너, 인기 꽃다발 3개, 가게 소개, 오시는 길, 문의, 하단 정보
- `style.css`: CSS 그라데이션과 이모지 장식, 큰 글씨, 반응형 화면, 키보드 초점 스타일
- `script.js`: 문의 버튼의 데모 안내 창, 하단 연도 자동 표시
- `README.md`: 실행 및 수정 안내

## 확인 방법

1. 이 폴더의 `index.html`을 더블 클릭해 Chrome 또는 Edge로 엽니다.
2. 상단 메뉴를 누르면 해당 영역으로 이동합니다.
3. 전화 문의 버튼을 누르면 가상 가게라는 안내 창이 열립니다. 확인 버튼 또는 Esc로 닫을 수 있습니다. 예시 번호로 실제 전화를 걸지는 않습니다.
4. 브라우저 폭을 좁혀 모바일 구성을 확인합니다. 개발자 도구(F12)의 기기 도구 모음에서 375px, 390px, 768px 화면도 확인할 수 있습니다. 작은 화면에서는 꽃다발 카드가 한 줄에 하나씩 나타납니다.
5. Tab 키로 메뉴와 버튼을 이동하고 Enter로 실행해 볼 수 있습니다. Ctrl와 + 키로 글씨를 확대할 수도 있습니다.

설치나 빌드, 인터넷 연결 없이 열 수 있습니다. 네 파일을 같은 폴더에 두세요. 외부 사진, 글꼴, 라이브러리를 불러오지 않습니다.

## 예시 정보 수정

- 가게 이름, 소개, 꽃다발 가격, 주소, 영업시간: `index.html`
- 색상과 글씨 크기, 화면 배치: `style.css`
- 문의 동작: `script.js`

주소는 `서울시 ○○구 ○○로 123`, 전화번호는 `02-000-0000`으로 표시했습니다. 가격과 영업시간도 예시입니다. 실제 가게에 적용하려면 올바른 정보로 바꾸고, `script.js`의 `[data-phone]` 클릭 처리 코드를 제거해 `tel:` 링크가 작동하게 하세요. HTML의 두 전화 링크도 실제 번호로 변경하고 데모 문구를 정리하세요.
